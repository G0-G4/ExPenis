## Why

Цвет категории в аналитике сейчас зависит от её места в рейтинге сумм: при переходе между месяцами он меняется, а разные графики могут показывать одну категорию разными цветами. Задача [#25](https://github.com/G0-G4/ExPenis/issues/25) закрепляет цвет за категорией и позволяет пользователю менять его с синхронизацией между устройствами.

## What Changes

- Хранить постоянный цвет категории на бэкенде и возвращать его через существующий API категорий.
- Выдавать существующим и новым категориям цвет из общей палитры из 32 цветов; сначала использовать свободные цвета пользователя, после исчерпания допускать повторения.
- Добавить выбор цвета в редактирование категории. Новые категории получают цвет автоматически; вручную можно выбрать уже занятый цвет.
- Использовать сохранённый цвет во всех разбивках аналитики: круговой диаграмме, помесячных столбиках и подробном списке. Сохранить серый агрегат «Остальные», показывая индивидуальные цвета его категорий в подробном списке.
- Сохранить существующее ограничение количества отдельных категорий на графиках независимо от увеличения палитры.
- Сохранять цвет при переименовании, смене типа и обновлении старым клиентом без поля цвета.
- Использовать существующие данные категорий в памяти экрана; получать изменения с другого устройства при следующей обычной загрузке, без дискового кэша и realtime-синхронизации.

## Capabilities

### New Capabilities

- `category-colors`: серверное назначение, хранение и пользовательское изменение цвета категории, совместимость API и согласованное отображение в аналитике.

### Modified Capabilities

Нет. Существующие требования фильтрации аналитики не меняются.

## Impact

- Backend: модель Category, новая SQL-миграция с заполнением существующих категорий, сервис категорий и создание стандартных категорий, DTO и существующие маршруты категорий; проверка принадлежности категории пользователю в затронутом чтении/обновлении.
- API: дополнительное поле цвета, совместимое обновление без этого поля; увеличение backend version и регенерация `docs/openapi.json`.
- Flutter: модель и сервис категорий, редактор категории, палитра, построение данных и подробная разбивка в `transaction_stats_screen.dart`; явное определение принадлежности к «Остальным» вместо сравнения цвета с серым.
- Проверки: миграция, сервис/API категорий, Flutter-модель, выбор цвета и стабильность цветов графиков при смене периода/фильтров/ранга.
- Новые зависимости, отдельные запросы за цветами, изменения оформления операций и публикация релиза не требуются.
