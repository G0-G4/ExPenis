# Проверка add-amount-expressions

Дата: 2026-11-21. Финальный выбор после сравнения — системная текстовая клавиатура с ручным переключением на символы/цифровую панель. Вариант со своей клавиатурой сохранён исторически в коммите `cf72633`.

## Автоматические проверки финального варианта

- Целевые `flutter test --no-pub test/amount_expression_test.dart test/amount_expression_field_test.dart test/amount_forms_test.dart`: 20 тестов прошли.
- Полный `flutter test --no-pub` на текущем рабочем дереве: 97 тестов прошли (включая параллельно добавленные тесты персональных сообщений).
- `flutter analyze --no-pub`: замечаний нет.
- `dart format --output=none --set-exit-if-changed` для 5 изменённых Dart-файлов: изменений нет.
- Проверены приоритет операций, скобки, знаки, точка/запятая, варианты символов операций, отсутствие промежуточного округления, половины копейки обоих знаков, ноль, отрицательные суммы, ошибки/лимиты и преобразование в API-число.
- Проверены создание/редактирование операции, начальный баланс и изменение итогового баланса. Запросы содержат округлённое число; неверный ввод не вызывает запись. После ошибки сети выражение остаётся для повторной отправки. Повторное открытие показывает число.
- Widget-тесты подтверждают `TextInputType.text`, обычный IME, Done без submit, выделение Meta+A, замену/удаление через IME, переход к другому полю и видимость preview при keyboard insets в обеих ориентациях с масштабом текста 2.

## Браузерный e2e

Итоговый запуск нативного варианта использует debug web на 8080 с `EXPENIS_API_BASE_URL=http://127.0.0.1:8100` и отдельный backend 8100 с временной SQLite-БД из текущих миграций. Backend Pixel на 8000 и рабочая БД не затронуты.

- Создание счёта `1000/3` и расхода `40+5/2`: ожидаются начальный баланс `333.33`, расход `42.50`, итоговый баланс `290.83`; повторное открытие операции показывает `42.5` вместо выражения.
- Телефонный viewport 390×844 и 844×390: текстовый ввод выражения, деление на ноль, исправление удалением, preview, Enter без submit и переход к текстовому полю. Отдельная панель калькулятора не показывается.
- Снимки `native-input-portrait.png` и `native-input-landscape.png` создаются в `tmp_path` e2e-теста. Desktop Chrome не воспроизводит мобильную экранную клавиатуру.

**Итоговый e2e (`E2E_API_URL=http://127.0.0.1:8100 just e2e`): 4 прошли, 1 пропущен, 39.54 с.** Пропущенный сценарий персональных сообщений относится к параллельной работе; два auth-сценария и оба сценария денежных полей прошли.

## Реальный Pixel 6a

- Установлены отдельные сравниваемые сборки `MyPennies Keyboard` и `MyPennies Native`; исходная подписанная версия приложения сохранена. Используется изолированный локальный backend через USB reverse порта 8000.
- В нативной сборке проверены вход, форма операции, ввод выражения и preview; пользователь вручную проверил цифровую панель с операциями. На снимке пользовательского ввода `125+85+78` показан результат `288`.
- Системная текстовая клавиатура позволяет вручную включить панель с цифрами и `+ - * /`. Автоматический выбор именно этого внутреннего режима не обеспечивается API типа поля.
- Отдельный временный probe проверил обычный Number, Signed decimal и Date time: они открывают другие панели без полного набора операций. Probe удалён, пользователь возвращён в свою открытую форму.
- Эти проверки относятся к нативному варианту сравнения с той же моделью ввода; они не являются полной проверкой всех версий Android, клавиатур или финального APK.
